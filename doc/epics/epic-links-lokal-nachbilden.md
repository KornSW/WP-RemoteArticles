# Epic: Links lokal nachbilden

Status: **für später vorgemerkt** (Wunsch vom 22.10.2026, Details folgen).

## Ziel

Links auf die Quellseite werden auf entsprechende Strukturen der **eigenen** Seite umgeschrieben, wenn die eigene Seite ähnliche Inhalte anbietet. Besucher bleiben so auf der eigenen Seite.

## Erste Gedanken

- Dafür braucht es eine Zuordnung von Quell-URLs zu lokalen Zielen, z. B.:
  - Quellkategorie → lokale Seite mit dem passenden Shortcode;
  - Quellbeitrag → Detailansicht des eingebetteten Beitrags auf der eigenen Seite.
- Eine Detailansicht je Beitrag setzt eigene Adressen auf der lokalen Seite voraus (Rewrite-Regeln oder ein Parameter auf einer Trägerseite). Das hängt mit der Frage nach der Darstellungsform im Epic [Remote-Beiträge per Shortcode](epic-remote-beitraege-per-shortcode.md) zusammen.
- Links ohne Zuordnung fallen auf einen der einfachen Modi aus dem [Link-Regelwerk](epic-link-regelwerk.md) zurück.
